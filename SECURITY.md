# Security Policy

## Supported Versions

I'm only supporting the latest version, and required changes will be released ASAP.

## Reporting a Vulnerability

Please report vulnerabilities privately, not in a public issue:

- Use GitHub's private vulnerability reporting: <https://github.com/JamesWoolfenden/sato/security/advisories/new>
- Or contact James Woolfenden at gmail dot com.

Helpful details: the affected version, the input that triggers it (for sato, usually a CloudFormation or ARM template), and the impact you expect.

## Disclosure Timeline

- **Acknowledgement:** within 7 days of your report.
- **Assessment:** I will confirm or decline the report, with reasons, within 14 days.
- **Fix:** accepted reports are fixed and released as soon as practical, targeting 30 days for medium severity and below, and sooner for high or critical.
- **Disclosure:** once a patched release is available, I publish a GitHub Security Advisory (with a CVE where one applies) and credit the reporter unless you ask me not to.

I follow coordinated disclosure: please give me the chance to ship a fix before publishing details. If you need a different timeline, say so in your report and we will agree one.
